How to highlight a PDF

  1. Drop your PDF into the box above.
  2. Pick a highlight color and opacity.
  3. Click and drag on the page to draw a highlight rectangle.
  4. Repeat as needed (undo or clear any time).
  5. Click Save PDF.

Technical limitations

  • Highlights are drawn as solid rectangles on the page. They are not PDF text-highlight annotation objects, so they won't move with text reflow.
  • Only the current page is highlighted. Switch pages via the file menu — actually, this tool works with one page at a time. For multi-page highlighting, use the PDF Editor.
  • Highlights use multiply-blend-like effect — text remains readable beneath them.

Frequently asked

Are highlights searchable?

No. They're visual rectangles drawn over the page content.

Can I highlight on multiple pages?

Currently this tool works on the first page only for simplicity. Use the PDF Editor for multi-page highlighting.
