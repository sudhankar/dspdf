How to add an image to a PDF

  1. Drop your PDF into the box above.
  2. Choose the image file you want to insert.
  3. Set position (9-grid), width, opacity, and which pages.
  4. Click Apply & Download.

Technical limitations

  • PNG and JPG embed directly. WebP is automatically re-encoded to PNG.
  • The image is placed at a fixed position — free-form drag-and-drop placement is available in the PDF Editor.
  • Aspect ratio is preserved — you set width and the height follows.

Frequently asked

Can I add an image to only some pages?

Yes. Use the Pages selector — All, First, Last, or a custom range.

Can I place the image freely?

Not here — this tool uses a 9-grid position picker. For free placement, use the PDF Editor.

Privacy

Add Image to PDF processes the selected PDF in your browser rather than sending it to a DSPDF PDF-processing server. Your browser may load public libraries needed for the tool, while your device controls memory and processing speed. For sensitive documents, keep the original and follow your own document-handling rules.
