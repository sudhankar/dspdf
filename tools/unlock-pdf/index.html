Unlock PDF

Remove protection from a PDF you own — when you already know the password.

🔒 Processed locally in your browser.

⚠ Only for files you own.
This tool removes protection from PDFs where you already know the password. It does not crack unknown passwords. Using it on files you don't own may be illegal in your jurisdiction.

Drop a protected PDF here or click to select

How to unlock a PDF

  1. Drop your protected PDF into the box above.
  2. Type the password you already know.
  3. Click Unlock & download.
  4. You receive a copy without encryption.

Technical limitations

  • No cracking. You must know the password. Brute-force attempts are not supported and never will be.
  • Owner password vs user password. Some PDFs allow viewing but restrict editing/printing via an owner password. Our tool removes protection only if the file opens with the password you provide.
  • Some AES-256 PDFs may not open. Very modern encryption schemes may not be fully supported by the browser stack.

Frequently asked

Can it crack unknown passwords?

No. This only removes protection from files you already have the password for.

Is it legal?

Only use it on files you own or have permission to modify.

My file still asks for a password after unlocking

That means the password you entered was incorrect — nothing was written. Try again with the correct password.

Privacy

Unlock PDF processes the selected PDF in your browser rather than sending it to a DSPDF PDF-processing server. Your browser may load public libraries needed for the tool, while your device controls memory and processing speed. For sensitive documents, keep the original and follow your own document-handling rules.
