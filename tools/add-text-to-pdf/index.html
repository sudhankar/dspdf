Add Text to PDF

Place new text anywhere on any page of your PDF — choose font, size, color, and alignment, then download.

🔒 Processed locally in your browser.

ℹ️
This tool adds new text on top of your PDF. Existing PDF text cannot be edited in a browser.

How to add text to a PDF

  1. Drop your PDF into the box above.
  2. Type the text you want to add.
  3. Choose font, size, color, and position on the page.
  4. Pick which pages (all, first, last, or custom range).
  5. Click Apply & Download.

Technical limitations

  • Only built-in PDF fonts (Helvetica, Times, Courier) are supported. Custom TTF embedding is on the roadmap.
  • This tool places text at a fixed position, not inside an editable flow. For free-form placement, use the PDF Editor.
  • Password-protected PDFs must be unlocked first.

Frequently asked

Can I edit existing PDF text?

No. This tool adds new text. Rewriting existing text would require reconstructing the PDF's layout, which is beyond what any browser library can do reliably.

What fonts are supported?

Helvetica, Times, and Courier — the standard fonts embedded in every PDF reader.

Can I put text at different positions on different pages?

Not in this tool. For per-page placement, use the PDF Editor.
