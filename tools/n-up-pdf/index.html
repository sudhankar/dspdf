N-up PDF

Combine several PDF pages into one sheet — 2-up, 4-up, 6-up, or 9-up. Save paper when printing handouts.

🔒 Processed locally in your browser.

Drop a PDF here or click to select

When N-up PDF is useful

N-up layouts place several original PDF pages on one sheet. This can be useful for handouts, review copies, slide notes, draft packets, or documents that you plan to print on standard paper. Choosing 2-up gives larger mini-pages, while 4-up, 6-up, and 9-up use more of the sheet and make the final document smaller.

Check the preview and readability before printing, especially when the source uses small text or detailed tables. Because this tool rasterizes pages for the compact layout, it is intended for visual handouts rather than preserving searchable text.

How to create an N-up PDF

  1. Drop your PDF into the box above.
  2. Pick 2-up, 4-up, 6-up, or 9-up.
  3. Choose sheet size, orientation, gap, and border.
  4. Click Create N-up PDF.

Technical limitations

  • Pages are scaled to fit their slot. Text becomes smaller.
  • Sheet count = ceil(total pages / pages-per-sheet). Last sheet may have empty slots.
  • Rasterizes the source (each mini page is an image) — output looks identical visually but text won't be searchable. Plan accordingly.
  • Page order flows left→right, top→bottom (like a book) when using 4-up+ landscape.

Frequently asked

Will text remain selectable?

No — this tool rasterizes pages. If you need N-up with searchable text, you'd need a PDF viewer's built-in N-up print driver.

What's the best setting for handouts?

4-up landscape is the standard for lecture handouts and slides.

Privacy

N-up PDF processes the selected PDF in your browser rather than sending it to a DSPDF PDF-processing server. Your browser may load public libraries needed for the tool, while your device controls memory and processing speed. For sensitive documents, keep the original and follow your own document-handling rules.
