N-up PDF

Combine several PDF pages into one sheet — 2-up, 4-up, 6-up, or 9-up. Save paper when printing handouts.

🔒 Processed locally in your browser.

Drop a PDF here or click to select

How to create an N-up PDF

  1. Drop your PDF into the box above.
  2. Pick 2-up, 4-up, 6-up, or 9-up.
  3. Choose sheet size, orientation, gap, and border.
  4. Click Create N-up PDF.

Technical limitations

  • Pages are scaled to fit their slot. Text becomes smaller.
  • Sheet count = ceil(total pages / pages-per-sheet). Last sheet may have empty slots.
  • Rasterizes the source (each mini page is an image) — output looks identical visually but text won't be searchable. Plan accordingly.
  • Page order flows left→right, top→bottom (like a book) when using 4-up+ landscape.

Frequently asked

Will text remain selectable?

No — this tool rasterizes pages. If you need N-up with searchable text, you'd need a PDF viewer's built-in N-up print driver.

What's the best setting for handouts?

4-up landscape is the standard for lecture handouts and slides.
