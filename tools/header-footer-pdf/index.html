How to add a header or footer

  1. Drop your PDF into the box above.
  2. Enter header text (optional) and/or footer text.
  3. Use {page}, {total}, or {date} as placeholders.
  4. Choose font, size, color, alignment, and margin.
  5. Pick which pages (skip the first page for cover-page reports).
  6. Click Apply header/footer.

Technical limitations

  • Header and footer text is drawn on each page as new text — it does not flow with existing content.
  • Only standard PDF fonts are supported (Helvetica, Times, Courier).
  • Date format is fixed as YYYY-MM-DD; custom date formats are on the roadmap.
  • Margins are measured from the page edge. Very tight margins (under 15pt) can collide with existing content.

Frequently asked

What placeholders are supported?

{page}, {total}, and {date}. Anything else is treated as literal text.

Can I have different text in header vs footer?

Yes. Each has its own text and alignment setting.

How do I skip the cover page?

Use "Skip first page" in the Pages dropdown, or specify a custom range like 2-20.
