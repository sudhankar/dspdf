What to include

If you're reporting a bug, the more of this you can include, the faster we can help:

  • Which tool — for example "Merge PDF" or "Compress PDF".
  • What you expected — what should have happened.
  • What actually happened — what did happen instead.
  • Error messages — copy the exact text if any appeared.
  • Browser and version — e.g. "Chrome 121 on Windows 11" or "Safari on iOS 17.2".
  • Approximate file size and page count — is it a small file or a 500-page monster? This narrows things down considerably.

Please don't attach the PDF itself unless we specifically ask for it. Your documents are your own; we don't want to see them unless it's necessary for a bug fix.

Feature requests

We love these. Tell us what you want to do and what's currently getting in the way. Sometimes the answer is "we already have a tool that does that, here's where it is". Sometimes it's a genuinely useful idea we hadn't thought of.

Things we already know we'd like to build: page reordering, custom TTF fonts in the editor, better Hindi OCR. If you're requesting any of those, you can skip the email — they're on the roadmap.

Privacy questions

If you have a question about how DSPDF handles your files (short answer: it doesn't), see the Privacy Policy first — it covers most common questions in detail. If your question isn't answered there, email us.

Security disclosures

If you've found a security issue, please email us with details rather than posting publicly. We'll respond as quickly as we can, and we'll credit you if you'd like.

Business and partnerships

For anything else — press enquiries, partnership ideas, or sponsorship — use the same email. We're a small operation, so we can't always say yes, but we'll always reply.
